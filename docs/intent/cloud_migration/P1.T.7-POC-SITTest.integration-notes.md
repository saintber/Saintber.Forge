## 系統參數與組態取得方式

### 參數來源說明
- 所有外部系統串接所需參數，皆透過系統參數機制取得。
- 現行實作由 `DBCMManager` 提供參數存取能力。

### 參數存取慣例（示意）
```csharp
// 範例用途，非設計約束
dbcm.GetParaValue("<Namespace>", "<Group>", "<Key>");
````

### 參數鍵對照（Parameter Contract）

> 說明：以下鍵值為目前已確認之參數契約；未確認者以 Unknown 標示。

- Redis：Unknown
- GCS：Unknown
- Postgres：透過 IMasDbContext 連線
- Fda API：
  - apiKey: ("AD", "fda_api_key", "01")
  - secureKey: ("AD", "fda_secure_key", "01")
  - SRU1: ("AD", "fda_url", "01")
  - SRU2: ("AD", "fda_url", "02")
- 統一企業 FTP：
  - ip: ("CR", "crt011", "ftp_server")
  - username: ("CR", "crt011", "ftp_username")
  - password: ("CR", "crt011", "ftp_pwd")
- 超商 SFTP：
  - ip: ("CR", "crt011", "sftp_server")
  - port: ("CR", "crt011", "sftp_port")
  - username: ("CR", "crt011", "sftp_username")
  - password: ("CR", "crt011", "sftp_pwd")
- PTC WebService：
  - url: ("CR", "crt015", "ws_url")

  - Server1: ("BU", "mail_server", sender/host/port/c_user/c_pwd/use_ssl)

## 外部系統串接說明

### 非追不可（FDA）API

* Token 取得端點：

  * `{SRU1}/webapi/rest/取得Token`

* Request 範例：

```json
{
  "APIKEY": "<apiKey>",
  "SECUREKEY": "<secureKey>"
}
```

* 備註：

  * Token 有效期限尚未確認
  * 錯誤回應與 retry 行為於 POC 階段未強制定義

---

### Redis

* 狀態：尚未確認（Unknown）
* 備註：

  * 僅需驗證基本連線能力
  * 驗證方式與驗證帳密待後續確認

---

### Google Cloud Storage（GCS）

* 狀態：尚未確認（Unknown）
* 備註：

  * 僅需驗證可進行基本存取操作
  * 憑證與授權方式待後續確認

---

### FTP / SFTP

#### FTP（統一企業）

* Server：由系統參數取得
* 驗證方式：帳號 / 密碼

#### SFTP（超商）

* Server：由系統參數取得
* Port：由系統參數取得
* 驗證方式：帳號 / 密碼（POC 階段）

---

### PTC WebService

* 連線 URL：由系統參數取得
* 備註：

  * 僅驗證可正常發送 request 並接收 response

---

### MailRelay

* Server1 / Server2：

  * Sender
  * Host
  * Port
  * CredentialUser
  * CredentialPassword
  * EnableSsl

* 備註：

  * Server2 為備援設定，實際可用性依環境而定

---

## POC 階段暫定決策（Provisional Decisions）

* 串接成功定義：

  * 可成功建立連線並完成基本通訊（handshake / request-response）
* POC 階段不強制定義 retry 策略
* 串接失敗時：

  * 紀錄錯誤資訊
  * 不影響其他周邊驗測項目之執行
