# Hub 有效規格索引

有效規格依 capability 放在 `<capability>/spec.md`，只記已驗證並採納的現行行為；同一 capability、requirement ID 只有一個有效定義。

**目前尚無 Hub 有效規格。** [`001-stage1-speckit-extension`](../../specs/001-stage1-speckit-extension/spec.md) 是未採納工作包，完整擴充設計仍待使用者確認；不要把它或設計快照直接複製成現況。
